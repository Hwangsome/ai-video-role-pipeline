# Full Role Contracts (Ask First + Product Insight + Market + Platform)

## Step 0 — First Ask User (before roles)
Always ask for:
1. 已有产品图 / 素材情况
2. 卖点（用户可说不确定，再结合网上研究）
3. 痛点（用户可说不确定，再结合网上研究）
4. 目标市场 + 平台（可选，有默认）

Do not run full pipeline until these are collected or user explicitly says “你直接定”.

## 1. Content Strategist
Goal: After Step 0 (+ optional research), lock type + 目标市场 + 目标平台 + 卖点 & 痛点 + produce concept_brief.md.
Required: 视频类型, 目标市场, 目标平台, 核心概念, 痛点(带来源), 卖点(带来源), 已有/需要的产品图情况, 其他字段.
Stop: Brief complete.
Handoff: Only concept_brief.md.

## 2. Narrative & Shot Director
Goal: Type + market + platform adapted shot_list.md that forces 痛点 → 卖点 demonstration.
Tone, pacing, humor, length habits, cultural and platform references must match.
Each shot notes which pain or benefit it serves.
Stop: Shot list complete.
Handoff: shot_list.md + brief.

## 3. Visual & Persona Reference Designer
Goal: Exact image list (≤9) + ref_map.md. Prefer user-provided product images; clearly list what still needs to be generated or shot.
Stop: Every image has clear purpose.
Handoff: map + upstream.

## 4. Seedance Multi-Type Prompt Engineer
Goal: Production-ready prompt with correct @ syntax that demonstrates 卖点, contrasts 痛点, and matches target market + platform style.
Stop: Self-checked.
Handoff: prompts + upstream.

## 5. Generation & Type-QA Specialist
Goal: Final Seedance Asset Package including Product Insight Summary (目标市场 + 目标平台 + 来源标注) + Required Images + Ready-to-Paste Prompt + Parameters + QA.
Stop: Package complete.
Handoff: Deliver to user.
