# Full Role Contracts (Product Insight + Market + Platform)

## 1. Content Strategist
Goal: Lock type + **目标市场** + **目标平台** + extract/confirm 用户痛点 & 核心卖点 + produce concept_brief.md.
Required: 视频类型, 目标市场, 目标平台, 核心概念（含痛点→卖点逻辑且符合市场+平台风格）, 痛点, 卖点, 其他字段.
If market/platform unspecified → apply defaults (中国大陆 + 抖音) and state them.
If 卖点/痛点 missing → research or mark [推断].
Stop: Brief complete.
Handoff: Only concept_brief.md.

## 2. Narrative & Shot Director
Goal: Type + market + platform adapted shot_list.md that forces 痛点 → 卖点 demonstration.
Tone, pacing, humor, length habits, cultural and platform references must match.
Each shot notes which pain or benefit it serves.
Stop: Shot list complete.
Handoff: shot_list.md + brief.

## 3. Visual & Persona Reference Designer
Goal: Exact image list (≤9) + ref_map.md supporting story, product proof, and market/platform aesthetic.
Stop: Every image has clear purpose.
Handoff: map + upstream.

## 4. Seedance Multi-Type Prompt Engineer
Goal: Production-ready prompt with correct @ syntax that demonstrates 卖点, contrasts 痛点, and matches target market + platform style.
Stop: Self-checked.
Handoff: prompts + upstream.

## 5. Generation & Type-QA Specialist
Goal: Final Seedance Asset Package including Product Insight Summary (with 目标市场 + 目标平台) + Required Images + Ready-to-Paste Prompt + Parameters + QA (product relevance + market/platform fit).
Stop: Package complete.
Handoff: Deliver to user.
