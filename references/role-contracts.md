# Full Role Contracts (with Product Insight + Target Market)

## 1. Content Strategist
Goal: Lock type + **目标市场/国家** + extract/confirm 用户痛点 & 核心卖点 + produce concept_brief.md.
Required: 视频类型, 目标市场, 核心概念（含痛点→卖点逻辑且符合市场风格）, 痛点, 卖点, 其他字段.
If market unspecified → default 中国大陆 and state it.
If 卖点/痛点 missing → research or mark [推断].
Stop: Brief complete.
Handoff: Only concept_brief.md.

## 2. Narrative & Shot Director
Goal: Type-adapted + market-adapted shot_list.md that forces 痛点 → 卖点 demonstration.
Tone, pacing, humor, cultural references must match target market.
Each shot notes which pain or benefit it serves.
Stop: Shot list complete.
Handoff: shot_list.md + brief.

## 3. Visual & Persona Reference Designer
Goal: Exact image list (≤9) + ref_map.md supporting story, product proof, and market aesthetic.
Stop: Every image has clear purpose.
Handoff: map + upstream.

## 4. Seedance Multi-Type Prompt Engineer
Goal: Production-ready prompt with correct @ syntax that demonstrates 卖点, contrasts 痛点, and matches target market style.
Stop: Self-checked.
Handoff: prompts + upstream.

## 5. Generation & Type-QA Specialist
Goal: Final Seedance Asset Package including Product Insight Summary (with 目标市场) + Required Images + Ready-to-Paste Prompt + Parameters + QA (product relevance + market fit).
Stop: Package complete.
Handoff: Deliver to user.
