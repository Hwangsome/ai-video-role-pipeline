# AI Video Role Pipeline Skill (Seedance 2.0 Ready)

Optimized multi-type AI video creation skill. Final output is a **copy-paste-ready Seedance Asset Package**.

## Key Features
- Strict Seedance 2.0 @ reference syntax and constraints
- Explicit image role assignments (first frame, character, product detail…)
- Time-segmented prompts
- **Product selling points (卖点) + user pain points (痛点) are required and woven into every narrative**
- Supports extracting 卖点 from product images or accepting user-provided lists
- Final deliverable designed for direct upload + paste into Seedance / Jimeng

## Supported Types
产品展示 · 生活种草 · 人物口播 · 搞怪离谱 · 剧情反转 · 感官氛围/ASMR · 伪纪录/采访
