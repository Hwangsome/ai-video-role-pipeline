# Seedance 2.0 Type-Specific Prompt Templates

Always combine with explicit @Image role assignments.

## 产品展示
Clean commercial flow. Emphasize product clarity, feature demo, result.
```
@Image1 as the first frame / hero product. 
0–3s: Product enters with slow rotation or push-in, close-up on texture and logo.
3–7s: Demonstrate key usage action with smooth tracking shot.
7–10s: Result / clean finish, product hero shot.
Bright even lighting, high detail product commercial style. Soft ambient music + subtle product interaction SFX.
```

## 生活种草
Natural lifestyle insertion. Soft recommendation feel.
```
@Image1 as first frame (product in real scene). 
In a real everyday environment, the product appears naturally. Soft handheld or gentle tracking. Show seamless integration into daily routine. End with subtle positive reaction. Warm natural light, authentic lifestyle aesthetic. Soft background music, natural ambient sounds.
```

## 人物口播
Face + speech focused. Lip-sync critical. (Avoid realistic face refs if possible; use stylized or product focus.)
```
@Image1 as character reference. Medium close-up, speaking clearly with natural gestures. Occasional cutaways to supporting visuals. Dialogue in double quotes for lip-sync. Clean background, professional yet approachable. Clear voice + light background music.
```

## 搞怪离谱（必须足够离谱）
Extreme absurd comedy. 动作和逻辑要夸张到不合理、让人觉得「这也行？」。
核心结构优先使用「别人的产品很惨 / 很普通 → 我们的产品夸张地超强」。
```
@Image1 as the product / first frame.
0–3s: 用其他普通马桶刷（或同类产品）认真清洁，结果很惨：刷头脏、水花乱溅、怎么刷都刷不干净，表情无奈崩溃。
3–8s: 突然拿出我们的一次性马桶刷，动作夸张到离谱——刷一下立刻锃亮、污垢像被磁铁吸走、刷头还能当麦克风唱歌、当指挥棒、当武器挥舞，整个人像开了挂。
8–11s: 用完直接扔掉，一脸「这很正常」的冷静，字幕或语气强调「一次性，用完就扔，干净到离谱」。
Fast cuts, shaky energy when crazy, sudden calm at the end. High-energy absurd comedy, extreme visual contrast between “别人的不行” and “我们的超强”.
```

## 剧情反转 / 强反差
Clear, exaggerated contrast. 预期被大幅打破，反差要夸张。
优先结构：别人的很普通/很烦 → 我们的出现后效果被夸张放大。
```
@Image1 as opening frame.
0–4s: 建立强烈预期——用普通产品怎么都弄不好，痛点被放大到夸张程度（脏、臭、麻烦、崩溃）。
4–8s: 我们的产品出现，效果被夸张表现（一次搞定、干净到反光、轻松到离谱）。
8–12s: 反转后的新现实 + 冷静或得意反应，强调卖点。
Camera and soundtrack must shift hard with the contrast. Emotional swing should be readable and over-the-top.
```

## 感官氛围 / ASMR
Sound-first, macro, slow rhythm.
```
@Image1 as first frame (texture close-up). Extreme close-ups of textures, hands, and micro-actions. Slow deliberate camera moves. Rich layered sound design described in detail (crinkles, soft taps, liquid, fabric). Minimal dialogue. Soft diffused lighting, intimate atmosphere. Prioritize audio immersion over story.
```

## 伪纪录 / 采访
Observational + interview hybrid.
```
@Image1 as establishing / interview frame. Handheld observational shots mixed with direct-to-camera interview moments. Natural available light, slight imperfections allowed. Subject speaks candidly. Cutaways to real environment details. Documentary framing, authentic tone, minimal music.
```
