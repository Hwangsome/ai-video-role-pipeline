# Seedance 2.0 @ Reference & Prompt Syntax Cheat Sheet

## Mandatory Role Assignment Examples
- `@Image1 as the first frame`
- `@Image2 as the last frame`
- `@Image1's character as the subject`
- `scene references @Image3`
- `product details reference @Image4`
- `wearing the outfit from @Image2`
- `reference @Video1's camera movement`
- `reference @Video1's action choreography`
- `completely reference @Video1's effects and transitions`
- `video rhythm references @Video1`
- `BGM references @Audio1`
- `sound effects reference @Video3's audio`

## Prompt Formula
[Subject/Character Setup with @] + [Scene/Environment] + [Action/Motion] + [Camera] + [Time segments if >8s] + [Transitions/Effects] + [Audio/Sound Design] + [Style/Mood]

## Camera Language (use these terms)
Push in, Pull back, Pan left/right, Tilt up/down, Track / Follow, Orbit / Revolve, Hitchcock zoom, Low angle, High angle, Bird's eye, Whip pan, Crane shot.
Shot sizes: Extreme close-up, Close-up, Medium close-up, Medium shot, Full shot, Wide / Establishing.

## Quality Modifiers
Cinematic quality, film grain, shallow depth of field, high detail, photorealistic product, soft natural light, bright commercial lighting, absurd comedy energy, ASMR intimate atmosphere.
